## 📖 About

Dyson Sphere Program is a sci-fi factory simulation developed by Youthcat Studio (released 2021). You begin on a single planet and must automate an interstellar industrial empire culminating in wrapping a star in a Dyson Sphere. The scale is breathtaking but progression quickly walls behind extremely specific resource chains that span multiple star systems.
